Amply v1.7.0
Release date: 2026-09-04

Highlights
- New neumorphic design system (light and dark), animated throughout, with a redesigned sidebar,
  cover-backed playlist cards, a proper EQ curve editor and a compact audio visualizer strip on
  the player bar (three styles).
- New smart-playlist engine: hard eligibility per mix (Most Played only contains played songs,
  Explore never repeats what you heard in the last 36 hours), artist/album caps that always hold,
  no song in more than two mixes, a "don't repeat yesterday" rule for the Daily Mix, a proper genre
  taxonomy, and cold-start mixes that differ from each other. Runs in a web worker.
- Listening signals fixed: a play counts only after 30 s / half the track, natural finishes are no
  longer double-counted, skips are tracked for every session, and a rolling listening log feeds
  the engine.
- Recommendations on the Search page: "Recommended for you" from your listening history, or
  "More like these" seeded by your current results.

Performance
- Album art is stored once per cover on disk and served through the amplyart protocol instead of
  travelling as base64 inside every song record: library cache, scan responses and memory shrink
  by orders of magnitude; 64/128 px thumbnails for lists.
- Parallel library scan; live EQ and speed changes without rebuilding the audio sink; instant
  seeking; idle audio thread; single SQLite connection with per-key metadata caches; batched
  artist-cache probe; render-loop fix on the Library page; playback state split so the queue is
  no longer rewritten every 5 seconds.
- The mix engine runs off the main thread, with a lite pass that regenerates only the five
  time-sensitive mixes after a play.

Interface
- Mini player: on/off toggle in the sidebar, a window margin so the raised edge is no longer
  clipped, and no compositor clip around the spinning artwork (the cause of the jagged edge).
- Audio visualizer moved out of the lyrics view onto the top edge of the player bar; the settings
  toggle now takes effect immediately instead of only after a restart.
- Lyrics auto-scroll no longer disengages on its own: only wheel, touch and keyboard gestures
  count as scrolling away, and a "Back to current line" button re-engages it.
- Smart playlist cards keep a stable snapshot; opening or playing a playlist no longer reshuffles
  the whole Home grid. Only the Refresh button regenerates.
- Sidebar entries are plain until hovered, with only the active entry pressed.
- Page eyebrow labels removed; Settings rows no longer repeat their section icon.
- Icons: the next/previous glyphs were 2.5 units off centre on the 24 grid and are now centred;
  the repeat glyph was two disconnected corners plus a stray diagonal and is now a real loop;
  the volume glyph reflects the level, so muting shows a muted speaker.

Metadata
- Artist details retry runs immediately with visible progress instead of silently waiting for an
  idle callback, and bypasses every cooldown.
- Wikipedia matching accepts producers, composers and instrumentalists, not only "band" and
  "singer", and only real transport failures are reported as offline.
- A real artist tag now always wins over an "Artist - Title" pattern in the title, so
  "Blackbird - 2018 Mix" by The Beatles is no longer looked up as artist "Blackbird". Lyrics
  search also tries the bare title for "Title - Version" names.
- Provider requests for recommendations go through the native HTTP client, which sidesteps the
  webview CORS restrictions that made Last.fm and MusicBrainz calls fail silently.

Fixes and hardening
- Seek bar freezing at 75 % on replayed tracks, position drift at non-1x speed, loop restarting
  at the seek offset, volume fighting the crossfade, m4a/aac not decoding.
- Content-Security-Policy, asset scope limited to the Music folder and scanned roots, file
  deletion confined to library folders, typed errors and structured logging, clean thread shutdown.
- Removed the unused Online page, the browser Howler engine and several dead commands.
- Routine MP3 decoder warnings (bit-reservoir underflow, bitrate-estimated duration) no longer
  flood the log.

Packaging
- Branded Windows installer: Amply header and sidebar artwork, app icon, per-user install,
  generated from the logo by scripts/installer-branding.py.
- Dependencies: Tauri 2.11, rodio 0.22, lofty 0.25, rusqlite 0.40, rfd 0.17, reqwest 0.13,
  tokio 1.53.

Validation
- npm run check (typecheck + eslint + 216 vitest tests), cargo check/clippy/test (41 tests),
  release build and NSIS installer.
- Decoder and tag-reader smoke tests against a real 1272-file library.
